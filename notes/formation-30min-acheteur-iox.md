# Formation 30 min — Acheteur B2B — IOX

**Version :** M97 / Mai 2026  
**Durée totale :** 30 minutes  
**Public :** Acheteur B2B professionnel (grossiste, restaurateur, distributeur, importateur)  
**Niveau requis :** Débutant — aucun jargon technique

---

> **Avant de commencer**  
> Avoir sous la main : un ordinateur ou smartphone, une connexion internet, votre email professionnel, l'email d'invitation IOX.

---

## Objectif de la formation (2 min)

À la fin de cette formation, vous saurez :
- Vous connecter à votre compte acheteur IOX
- Trouver des produits agricoles de l'océan Indien
- Envoyer une demande de devis à un vendeur
- Suivre votre demande et effectuer un paiement sécurisé

**Ce qu'IOX fait pour vous :** accès direct aux coopératives agricoles de Mayotte et de l'océan Indien. Demandes de devis structurées, traçabilité produit, paiements sécurisés via Stripe — tout en un seul endroit.

---

## Étape 1 — Connexion (2 min)

### Se connecter pour la première fois

1. Ouvrir l'email d'invitation IOX (expéditeur : `noreply@iox.example`)
   - Vérifier le dossier SPAM si non trouvé
2. Cliquer sur **"Activer mon compte"**
3. Définir un mot de passe (minimum 8 caractères)
4. Vous êtes connecté — tableau de bord acheteur affiché

### Se reconnecter

1. Aller sur `https://pilot.iox.example`
2. Cliquer **"Connexion"** en haut à droite
3. Email + mot de passe → **"Se connecter"**

### Mot de passe oublié

Cliquer **"Mot de passe oublié ?"** sous le formulaire → recevoir un email de réinitialisation → définir un nouveau mot de passe.

## Étape 2 — Explorer le catalogue (5 min)

### Accéder au catalogue

1. Dans le menu principal, cliquer sur **"Marketplace"** ou **"Catalogue"**
2. Vous voyez la liste de tous les produits disponibles

### Rechercher un produit

- **Barre de recherche** (en haut de la page) : taper le nom du produit
  - Exemple : `vanille`, `ylang-ylang`, `gingembre`, `banane`
  - La recherche est instantanée (résultats affichés en temps réel)

### Utiliser les filtres

À gauche de la page, plusieurs filtres sont disponibles :

| Filtre | Utilisation |
|---|---|
| Catégorie | Épices, Fruits, Légumes, Huiles essentielles... |
| Origine | Mayotte, La Réunion, Madagascar, Comores |
| Prix | Fourchette de prix par unité |
| Certifications | Bio, AOP, Equitable... |
| Disponibilité | En stock uniquement |

Combiner les filtres pour affiner votre recherche.

### Lire une fiche produit

Cliquer sur un produit pour voir :
- **Photos** du produit
- **Description** et caractéristiques
- **Prix** par unité (indicatif — le devis est personnalisé)
- **Quantité minimum** (MOQ)
- **Documents** : fiches techniques, certificats disponibles
- **Profil du vendeur** : coopérative, localisation, historique

## Étape 3 — Envoyer une demande de devis (RFQ) (8 min)

RFQ = *Request for Quotation* = Demande de devis. C'est la façon d'initier une négociation commerciale avec un vendeur sur IOX.

### Comment envoyer une RFQ

1. Sur la fiche produit, cliquer sur **"Demander un devis"**
2. Le formulaire de demande s'ouvre :

**Section 1 — Votre besoin**
- **Quantité souhaitée** : indiquer la quantité et l'unité (ex : 500 kg, 2 tonnes)
- **Date de livraison souhaitée** : quand vous avez besoin des marchandises
- **Incoterms** *(optionnel)* : EXW, FOB, CIF... (si vous avez une préférence)

**Section 2 — Vos coordonnées de livraison**
- Adresse de livraison
- Port ou aéroport de destination *(si applicable)*

**Section 3 — Message au vendeur** *(optionnel)*
- Questions spécifiques sur le produit
- Exigences particulières (conditionnement, étiquetage, certifications requises)
- Exemple : *"Avez-vous des certifications phytosanitaires pour l'export vers la France métropolitaine ?"*

3. Vérifier les informations
4. Cliquer **"Envoyer ma demande"**

### Ce qui se passe après

- Le vendeur reçoit votre demande immédiatement
- Vous recevez un email de confirmation
- Le vendeur a **48 heures** pour vous répondre

---

## Étape 4 — Suivre votre demande (5 min)

### Accéder au suivi

1. Dans le menu, cliquer sur **"Mes demandes"** ou **"Demandes de devis"**
2. Liste de toutes vos demandes avec leur statut

### Les statuts

| Statut | Signification |
|---|---|
| En attente | Le vendeur n'a pas encore répondu |
| Réponse reçue | Le vendeur a envoyé son devis — à examiner |
| Acceptée | Vous avez accepté le devis — paiement en cours |
| Annulée | La demande a été annulée |
| Terminée | Transaction complète |

### Notifications

Vous recevez un email à chaque changement de statut :
- Email de `notifications@iox.example` — vérifier le SPAM si non reçu
- Badge de notification dans l'application (point rouge sur l'icône cloche)

### Messagerie intégrée

Sur chaque demande de devis, un fil de messagerie permet d'échanger directement avec le vendeur :
1. Ouvrir la demande
2. Section **"Messages"** en bas de la page
3. Taper votre message et cliquer **"Envoyer"**

---

## Étape 5 — Paiement (5 min)

IOX utilise **Stripe** pour les paiements — la référence mondiale des paiements B2B en ligne.

### Processus de paiement

1. Vous recevez une réponse du vendeur avec son devis
2. Ouvrir la demande → lire le devis
3. Si le devis vous convient : cliquer **"Accepter le devis"**
4. Vous êtes redirigé vers la page de paiement Stripe
5. Entrer vos informations de paiement :
   - Carte bancaire professionnelle
   - Ou virement SEPA (selon configuration)
6. Confirmer le paiement
7. Vous recevez :
   - Un email de confirmation de paiement
   - Une **facture PDF** téléchargeable

### Sécurité des paiements

- Stripe est certifié **PCI DSS niveau 1** — le plus haut niveau de sécurité pour les paiements en ligne
- IOX ne stocke jamais vos informations de carte bancaire
- Toutes les transactions sont chiffrées

### Télécharger une facture

1. Dans le menu, cliquer sur **"Mes factures"**
2. Trouver la facture souhaitée
3. Cliquer **"Télécharger"** — format PDF

## Questions fréquentes (3 min)

**"Comment savoir si le vendeur a vu ma demande ?"**
→ Vous recevrez un email de notification dès que le vendeur **consulte** votre demande.
→ Dans l'application : ouvrir la demande → un badge **"Lu"** apparaît sous votre message.
→ Rappel : le vendeur a 48h pour répondre. Si pas de réponse, contacter le support IOX.

**"Je veux annuler une demande."**
→ Ouvrir la demande dans **"Mes demandes"**.
→ Le bouton **"Annuler la demande"** est disponible tant que le vendeur n'a pas accepté.
→ Une fois le devis accepté et le paiement initié, l'annulation n'est plus possible automatiquement — contacter le support IOX.

**"Comment télécharger ma facture ?"**
→ Aller dans **"Mes factures"** dans le menu.
→ Cliquer sur la facture de la commande souhaitée.
→ Bouton **"Télécharger (PDF)"** en haut à droite.
→ Si la facture n'apparaît pas, rafraîchir la page ou contacter le support.

**"Le vendeur ne répond pas à ma demande."**
→ Le vendeur a **48 heures** pour répondre.
→ Après 48h sans réponse : contacter le **support IOX** via WhatsApp ou email.
→ IOX peut relancer le vendeur ou vous suggérer un vendeur alternatif pour le même produit.

**"Stripe est-il sécurisé pour mes achats B2B ?"**
→ Oui. Stripe est certifié **PCI DSS niveau 1**, la norme la plus stricte pour les paiements en ligne.
→ Stripe traite les paiements de millions d'entreprises dans le monde (Amazon, Shopify, Deliveroo...).
→ Vos données bancaires ne transitent jamais par les serveurs IOX — elles vont directement à Stripe.
→ En cas de litige ou problème de paiement : contacter le support IOX qui ouvre un dossier Stripe.
