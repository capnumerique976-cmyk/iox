# Formation 30 min — Vendeur (Coopérative) — IOX

**Version :** M97 / Mai 2026  
**Durée totale :** 30 minutes  
**Public :** Gérant ou référent numérique d'une coopérative agricole  
**Niveau requis :** Débutant — aucun jargon technique

---

> **Avant de commencer**  
> Avoir sous la main : un smartphone ou ordinateur, une connexion internet, l'email d'invitation IOX reçu.

---

## Objectif de la formation (2 min)

À la fin de cette formation, vous saurez :
- Vous connecter à votre compte IOX
- Compléter le profil de votre coopérative
- Publier votre premier produit
- Recevoir et répondre à une demande de devis (RFQ)

**Ce qu'IOX fait pour vous :** met vos produits en contact avec des acheteurs B2B professionnels (grossistes, distributeurs, restaurateurs) dans l'océan Indien et au-delà. Vous recevez des demandes de devis, vous répondez, vous êtes payé via Stripe directement sur votre compte bancaire.

---

## Étape 1 — Connexion (3 min)

### Se connecter pour la première fois

1. Ouvrir l'email d'invitation IOX (expéditeur : `noreply@iox.example`)
   - Si vous ne trouvez pas l'email : **vérifier le dossier SPAM / Courrier indésirable**
2. Cliquer sur le bouton **"Activer mon compte"**
3. Choisir un mot de passe (minimum 8 caractères, avec 1 chiffre et 1 majuscule)
4. Vous êtes connecté

### Se reconnecter plus tard

1. Aller sur le site IOX : `https://pilot.iox.example`
2. Cliquer sur **"Connexion"** en haut à droite
3. Entrer votre email et mot de passe
4. Cliquer **"Se connecter"**

### Mot de passe oublié

1. Cliquer sur **"Mot de passe oublié ?"** sous le formulaire de connexion
2. Entrer votre adresse email
3. Recevoir un email avec un lien de réinitialisation
4. Créer un nouveau mot de passe

---

## Étape 2 — Profil coopérative (5 min)

Un profil complet inspire confiance aux acheteurs. Prenez 5 minutes pour le remplir.

### Comment accéder au profil

1. Une fois connecté, cliquer sur **votre nom** en haut à droite
2. Sélectionner **"Mon profil"** ou **"Paramètres"**
3. Vous êtes dans la page de profil de votre coopérative

### Informations à compléter

- **Nom de la coopérative** *(déjà pré-rempli avec les informations d'inscription)*
- **Description** : en 2-3 phrases, présentez votre coopérative et vos spécialités
  - Exemple : *"Coopérative agricole de Mayotte, spécialisée dans la vanille, l'ylang-ylang et les fruits tropicaux. Créée en 2005, nous regroupons 45 agriculteurs."*
- **Localisation** : ville, département, pays
- **Site web** *(si vous en avez un — sinon, laisser vide)*
- **Numéro de téléphone**

### Uploader le logo

1. Dans la section **"Logo"**, cliquer sur **"Changer l'image"**
2. Sélectionner un fichier depuis votre téléphone ou ordinateur
   - Formats acceptés : JPG, PNG
   - Taille maximale : 10 MB
   - Idéalement : image carrée, fond blanc ou transparent
3. Cliquer **"Enregistrer"**

> **Conseil :** Si vous n'avez pas de logo, une photo de votre exploitation ou d'un produit phare fonctionne très bien.

## Étape 3 — Publier un produit (10 min)

C'est l'action la plus importante. Voici comment publier votre premier produit étape par étape.

### Accéder à la création de produit

1. Dans le menu principal, cliquer sur **"Mes produits"**
2. Cliquer sur le bouton **"+ Nouveau produit"** (en haut à droite)

### Remplir la fiche produit

**Section 1 — Informations de base**
- **Nom du produit** : soyez précis et commercial
  - Bon exemple : *"Vanille de Mayotte — gousses premium grade A"*
  - Mauvais exemple : *"Vanille"*
- **Catégorie** : sélectionner dans la liste déroulante (ex : Épices, Fruits, Légumes...)
- **Description** : décrire le produit, son origine, ses caractéristiques
  - Minimum 2-3 phrases
  - Mentionner les certifications si vous en avez (bio, AOP, etc.)

**Section 2 — Prix et quantités**
- **Prix unitaire** : entrer le prix en euros (HT)
- **Unité** : kg, tonne, caisse, litre... (choisir dans la liste)
- **Quantité minimum de commande (MOQ)** : exemple 10 kg, 1 tonne
- **Stock disponible** : quantité disponible immédiatement

**Section 3 — Photos**
- Cliquer sur **"Ajouter des photos"**
- Sélectionner 1 à 5 photos du produit
- Formats : JPG, PNG — max 10 MB par photo
- Conseil : photos à la lumière naturelle, fond neutre, produit propre

**Section 4 — Documents (optionnel)**
- Certificats phytosanitaires, fiches techniques, certificats d'origine
- Formats acceptés : PDF, JPG, PNG — max 10 MB

### Publier le produit

1. Vérifier toutes les informations
2. Cliquer sur **"Publier le produit"**
3. Le produit apparaît maintenant dans le catalogue public IOX
4. Pour vérifier : aller sur `/marketplace` — votre produit doit être visible

> **Conseil pilote :** Commencer par vos 3 produits les plus connus et les mieux photographiés.

## Étape 4 — Recevoir une demande de devis (RFQ) (5 min)

RFQ = *Request for Quotation* = Demande de devis. Quand un acheteur est intéressé par votre produit, il vous envoie une RFQ.

### Vous recevrez une notification par email

- Expéditeur : `notifications@iox.example`
- Objet : *"Nouvelle demande de devis pour [nom produit]"*
- Si pas reçu après 5 minutes : vérifier le dossier SPAM

### Comment répondre à une RFQ

1. Cliquer sur le lien dans l'email **"Voir la demande"**
   — ou —
   Aller sur IOX → **"Demandes de devis"** dans le menu de gauche
2. Cliquer sur la demande en attente (badge orange)
3. Lire les informations de l'acheteur :
   - Quantité souhaitée
   - Date de livraison souhaitée
   - Questions spécifiques
4. Cliquer sur **"Répondre"**
5. Remplir :
   - Prix proposé (par unité ou total)
   - Délai de livraison que vous pouvez honorer
   - Commentaires ou conditions
6. Cliquer **"Envoyer ma réponse"**

> **Important :** Répondre dans les **48 heures**. Un acheteur sans réponse se tourne vers un concurrent.

### Suivi de la demande

- Si l'acheteur accepte votre devis → vous recevez une notification
- Le paiement Stripe est déclenché automatiquement
- Vous recevrez les fonds sur votre IBAN après la période de rétention Stripe (typiquement 2-7 jours)

## Questions fréquentes (5 min)

**"Je ne reçois pas les emails IOX."**
→ Vérifier le dossier **SPAM / Courrier indésirable** de votre messagerie.
→ Si IOX est dans le SPAM, faire un clic droit sur l'email → "Ne pas marquer comme spam" ou "Ajouter à mes contacts".
→ Si toujours pas reçu : contacter le support IOX via WhatsApp.

**"Je ne peux pas uploader mes documents (logo, photos, certificats)."**
→ Vérifier le **format** : seuls les formats **PDF, JPG et PNG** sont acceptés.
→ Vérifier la **taille** : maximum **10 MB** par fichier. Réduire avec une application photo si besoin.
→ Si le problème persiste : envoyer le fichier par WhatsApp au support IOX qui l'importera pour vous.

**"Comment savoir si mon produit est bien en ligne ?"**
→ Aller sur `https://pilot.iox.example/marketplace` — sans être connecté.
→ Chercher le nom de votre produit dans la barre de recherche.
→ Si votre produit apparaît : il est en ligne et visible des acheteurs.

**"J'ai une demande de devis — que dois-je faire ?"**
→ Cliquer sur **"Demandes de devis"** dans le menu.
→ Ouvrir la demande (badge orange = non traitée).
→ Cliquer **"Répondre"**, remplir le formulaire, envoyer.
→ À faire dans les **48 heures** pour ne pas perdre l'acheteur.

**"Je veux changer le prix de mon produit."**
→ Aller dans **"Mes produits"**.
→ Cliquer sur le produit à modifier.
→ Cliquer **"Modifier"** (bouton crayon).
→ Changer le prix et cliquer **"Enregistrer"**.
→ Le nouveau prix est immédiatement visible sur le catalogue.
