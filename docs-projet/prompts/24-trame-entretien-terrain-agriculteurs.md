# Trame entretien terrain — agriculteurs IOX (45-60 min/persona)

> Trame pour 5-8 entretiens avant design app mobile. Test cibles : Saïd / Maeva / Jean-Bruno (cf brief 23). Présentiel obligatoire. Smartphone du persona = outil principal de l'entretien.

---

## 0. Préparation (avant entretien)

**Matériel** :
- Smartphone interviewer (enregistrer audio + photos selon consentement)
- Carnet papier + stylo (low-tech backup)
- 3 maquettes papier A4 imprimées (concepts WhatsApp / Photo-first / Liste épurée)
- 5 photos test de catégories produit (vanille / mangue / café / ylang-ylang / cacao) — pour test reconnaissance pictogramme
- Cartes mémo pictogrammes (caméra / micro / send / etc.) à montrer
- Eau, snack, ombre

**Préparation persona** :
- Saïd → traducteur shimaoré présent, voix posée, pas de jargon
- Maeva → bilingue FR-malgache, ton normal
- Jean-Bruno → direct, peut faire en 30 min

**Recrutement** :
- Via agent MCH terrain
- Mix genres, mix âges (30-65)
- Mix produits (vanille, fruits, café, ylang)
- Indemnité forfait journée prévue (sortie de plantation = perte revenu)

**Consentement** :
- Enregistrement audio = OUI/NON explicite
- Photos = uniquement objets/main, pas visage sauf accord
- Anonymisation rapport (prénom changé)
- Droit retrait à tout moment

---

## 1. Ouverture (5 min)

Objectif : mise en confiance. Pas de questions piège. Pas de "test".

**Script** :

```
"Bonjour [nom]. Merci de votre temps. Je travaille sur un outil pour aider
les producteurs comme vous à vendre plus facilement à des acheteurs lointains.
Avant de construire l'outil, je veux comprendre comment vous travaillez aujourd'hui.

Il n'y a pas de bonne ou mauvaise réponse. Je veux juste apprendre de vous.
Vous pouvez répondre en [langue préférée]. Si une question ne vous parle pas,
on passe.

OK pour qu'on parle 45-60 minutes ?"
```

**Si Saïd** : ajouter "Je travaille avec MCH. C'est OK avec eux." Réassurance institutionnelle.

---

## 2. Vie quotidienne + pratiques agricoles (10 min)

But : comprendre rythme, vocabulaire, stress.

**Questions ouvertes** :

- "Racontez-moi une journée type. Vous vous levez quand, vous faites quoi ?"
- "Combien d'hectares / arbres / plants vous gérez ?"
- "Vous travaillez seul ou en coopérative ?"
- "Période de récolte = quand ? Combien de temps ça dure ?"
- "Qu'est-ce qui vous prend le plus de temps dans la semaine ?"
- "Qu'est-ce qui vous stresse le plus dans votre métier ?"

**Observer** :
- Vocabulaire utilisé (note les mots métier)
- Cadence réponse (rapide = à l'aise / silences = sujet sensible)
- Gestes (montre les mains s'il a parlé travail manuel)

---

## 3. Pratiques numériques actuelles (10 min)

But : cartographier outils + comportements existants.

**Questions** :

- "Vous avez quel téléphone ? Montrez-moi." → photo si OK
- "Combien de temps par jour vous l'utilisez ?"
- "Quelles applications vous ouvrez en premier le matin ?"
- "WhatsApp ? À qui vous écrivez ? Photos / vocal / texte écrit ?"
- "Facebook ? TikTok ? Pour quoi ?"
- "Vous avez déjà acheté quelque chose en ligne ? Si oui, comment ?"
- "Vous payez avec quoi : cash / mobile money / carte / virement ?"
- "Si une appli vous demande votre email, vous savez quoi répondre ?"
- "Si une appli plante, vous faites quoi ?"

**Demander démo** :
- "Montrez-moi comment vous envoyez un message vocal à un ami." → observer fluidité
- "Si je vous dis 'rechercher YouTube', vous le faites ?" → observer barre URL vs voice search

**Mesurer (mentalement)** :
- Score littératie numérique : 1 (Saïd) à 5 (Jean-Bruno)
- Nb apps utilisées régulièrement
- Présence de blocages mentaux ("c'est trop compliqué", "j'ai peur de casser")

---

## 4. Pratiques commerciales actuelles (10 min)

But : journey existant vente B2B. Pain points à attaquer.

**Questions** :

- "Comment vous vendez votre [vanille/café/etc.] aujourd'hui ?"
- "Qui sont vos acheteurs ? Locaux ? Lointains ? Combien d'acheteurs réguliers ?"
- "Comment ils découvrent vos produits ?"
- "Comment vous fixez le prix ?"
- "Combien de temps entre demande acheteur et livraison ?"
- "Vous avez déjà perdu une vente ? Pourquoi ?"
- "Le plus difficile dans la vente = quoi ?"
- "Vous tenez un cahier / registre / Excel des ventes ?" → demander à voir
- "Si un acheteur en France vous écrit demain, vous savez quoi faire ?"

**Pain points typiques attendus** :
- Délai paiement
- Exigences qualité floues côté acheteur
- Logistique (transport, douane)
- Langue (acheteur parle pas FR)
- Fluctuation prix
- Confiance acheteur lointain

---

## 5. Test maquettes papier (15 min)

But : valider concepts avant codage. Détecter incompréhensions.

**Protocole** :
1. Sortir maquette concept A (WhatsApp marketplace) → "Voici un écran. Que voyez-vous ? Que feriez-vous en premier ?"
2. Observer pointage doigt + verbalisation
3. Donner tâche : "Vous voulez ajouter votre vanille à vendre. Montrez-moi."
4. Noter : succès / échec / confusion / abandon
5. Idem concept B (Photo-first) puis concept C (Liste épurée)
6. Question finale : "Lequel des trois vous parle le plus ? Pourquoi ?"

**Tests pictogrammes** :
- Montrer 5 cartes pictogrammes (caméra / micro / send avion / cloche notification / oeil)
- "Que représente ça pour vous ?"
- Noter mots utilisés (caméra ou photo ou appareil ?)

**Tests catégories produit** :
- Montrer 5 photos (vanille gousse / mangue / grain café / fleur ylang / cabosse cacao)
- "C'est quoi ?"
- Tester variante illustration vs photo réaliste
- Noter quel style est mieux identifié

---

## 6. Aspirations + blocages (5 min)

But : extraire vision long terme + obstacles réels.

**Questions** :

- "Si vous aviez une baguette magique, votre métier serait comment ?"
- "Qu'est-ce qui vous empêche aujourd'hui de gagner plus ?"
- "Vous accepteriez d'apprendre une nouvelle appli ? Combien de temps max ?"
- "Si l'appli ne marche pas, vous abandonnez ou vous appelez quelqu'un ? Qui ?"
- "Une chose que je n'ai pas demandée mais qui compte pour vous ?"

**Verbatims à capturer** : phrases percutantes, mot pour mot, pour rapport synthèse.

---

## 7. Clôture (5 min)

- "Merci [nom]. Vos réponses sont précieuses."
- "Quand l'outil sera prêt, on revient vers vous pour vous montrer ?"
- "Vous voulez ajouter quelque chose ?"
- Indemnité remise.
- Photo souvenir si OK (consentement).
- Sortir sans précipitation.

---

## 8. Variante par persona

### Saïd (low-literacy num)

- **Allonger ouverture** à 8 min (mise en confiance critique)
- **Traducteur shimaoré** présent en backup
- **Pas de question écrite** sur smartphone
- **Section 5 maquettes** : faire pointer + verbaliser, jamais "lire à haute voix"
- **Section 6 aspirations** : reformuler en cas pratique ("si demain vous aviez 1 acheteur français...")

### Maeva (medium)

- **Cadence normale**, 50-60 min
- Section 3 + 4 = creuser plus (richesse réponses attendue)
- **Demander de montrer ses comptes Facebook/TikTok** professionnels si elle en a

### Jean-Bruno (expert)

- **Sauter section 1 ouverture** (5 min suffisent)
- **Approfondir section 4 commerciale** : Excel, courriels acheteurs, contrats
- **Section 5 maquettes** : aller direct au concept C (liste épurée) + demander critique design
- Durée totale 35-45 min

## 10. Synthèse globale (après 5-8 entretiens)

**Format livrable** : `docs-projet/research/synthese-recherche-utilisateur-mobile.md`

Sections :
1. Méthodo (qui, quand, où, comment)
2. Profils rencontrés (tableau résumé)
3. Cartographie pain points (matrice fréquence × intensité)
4. Patterns par persona (3 personas validés/affinés)
5. Test concepts (gagnant + raisons)
6. Test pictogrammes (lesquels universels, lesquels à retravailler)
7. Test catégories (photo vs illustration : verdict)
8. 10 verbatims percutants (1 par persona × ~3)
9. Implications design (5-10 prescriptions concrètes)
10. Limites étude (nb persona, biais recrutement, etc.)

---

## 11. Pièges à éviter

- **Questions orientées** : "Vous ne trouvez pas WhatsApp difficile ?" → préférer "Comment vous trouvez WhatsApp ?"
- **Jargon design / dev** : pas de "UX", "interface", "API", "backend"
- **Démos avant entretien** : montrer maquette en premier biaise tout. Maquettes = section 5 seulement.
- **Surinterprétation silence** : silence ≠ accord. Reformuler.
- **Saïd dit "oui" politesse** : tester en demandant de refaire la tâche → vraie compréhension révélée
- **Confondre "ce qu'ils disent" et "ce qu'ils font"** : observer geste = vérité, parole = filtre social
- **Design dans l'entretien** : pas proposer solution. Juste écouter, observer, capturer.
