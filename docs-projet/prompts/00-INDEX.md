## Convention

- Chaque prompt cite les invariants critiques du contexte canonique en tête (cf. `../13-contexte-canonique-marketplace.md` pour la version intégrale).
- Chaque prompt précise : objectif, branche, règles absolues, périmètre, méthodologie, tests attendus, critères de succès, gestion des blocages, format du rapport final.
- Les prompts sont conçus pour des sessions Claude Code de 30 min à 4 h selon l'ampleur du lot.
